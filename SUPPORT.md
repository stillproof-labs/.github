# Getting help

- **A photo or receipt didn't verify?** Run `stillproof verify --json PHOTO
  [RECEIPT]` and open a bug in [stillproof](https://github.com/stillproof-labs/stillproof/issues)
  with the output and, if you can share them, the files.
- **The anchoring service misbehaved?** Open a bug in
  [stillproof-anchor](https://github.com/stillproof-labs/stillproof-anchor/issues)
  with the request, the response and the network.
- **The app?** Open a bug in
  [stillproof-app](https://github.com/stillproof-labs/stillproof-app/issues)
  with the device, the OS version and what you saw.
- **What a receipt proves, byte by byte:** [SPEC.md](https://github.com/stillproof-labs/stillproof/blob/main/SPEC.md).
- **A receipt that verifies but shouldn't** is a security issue: report it
  privately as described in [SECURITY.md](SECURITY.md).
